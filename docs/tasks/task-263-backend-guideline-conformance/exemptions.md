`Model`. Five of the 176 rows are this false positive. Each has a genuine domain type and exactly

## DOM-04 — detector artifacts

detector limitations account for all six, three packages each; the evidence for both was

### (a) recursive-directory false positive — exempt

`split-by-model.sh`'s `grep -rqs --include='*.go' '^type Model ' "$(dirname "$f")"` walks
subdirectories, so a *subpackage's* `type Model` misfiles the parent package into `has-model` even
though the parent declares no domain `Model` of its own. Confirmed non-recursively for each: `grep
-n "^type Model " <pkg>/*.go` returns zero hits in the parent package; the `type Model` lives one
level down, in a subpackage.

- `services/atlas-consumables/atlas.com/consumables/monster` — no `type Model` in `monster/*.go`;
  the `type Model` is at `services/atlas-consumables/atlas.com/consumables/monster/drop/position/model.go:3`.
- `services/atlas-data/atlas.com/data/skill` — no `type Model` in `skill/*.go`; the `type Model` is
  at `services/atlas-data/atlas.com/data/skill/effect/model.go:16`.
- `services/atlas-maps/atlas.com/maps/character` — no `type Model` in `character/*.go`; the `type
  Model` is at `services/atlas-maps/atlas.com/maps/character/location/model.go:15`.

Disposition: exempt. These belong to the same "no domain `Model`" class as the DOM-04 §
"no domain Model in the package" packages above; the recursive grep is a detector artifact, not a
signal about the parent package itself.

### (b) displaced `Transform` — satisfied elsewhere, not exempt

`sweep.sh` greps only the package's `rest.go` file for `^func Transform(`. These three packages
each declare a domain `Model` and a conforming `func Transform(m Model) (RestModel, error)` — the
function simply lives in another file in the same package, alongside the file that declares
`RestModel`. **These three conform to DOM-04; they are not a form of debt.**

- `services/atlas-dragons/atlas.com/dragons/dragon` — `type Model` at `model.go:18`; `RestModel` and
  `func Transform(m Model) (RestModel, error)` both in `resource.go:41`.
- `services/atlas-storage/atlas.com/storage/asset` — `type Model` at `model.go:14`; `RestModel` and
  `func Transform(m Model) (RestModel, error)` both in `processor.go:100` (plus `func TransformAll`
  at `processor.go:138`).
- `services/atlas-summons/atlas.com/summons/summon` — `type Model` at `model.go:25`; `RestModel` and
  `func Transform(m Model) (RestModel, error)` both in `resource.go:44`.

Disposition: satisfied elsewhere. In all three the `RestModel` is declared in a file other than
`rest.go` (`resource.go` or `processor.go`), and the `Transform` function sits beside its
`RestModel` rather than in `rest.go` — a file-placement convention the DOM-04 detector does not
model, the same structural blind spot as the displaced-`Extract` cases Task 16 handled.
