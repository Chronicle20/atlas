## H3 — `yamlEntry(e)` conversion — PASS, behaviour-preserving

`libs/atlas-kafka/gen/manifest.go:14-40` (read in full during review):
```go
type Entry struct {
	Token    string
	Cleanup  string
	Packages []string
}
...
type yamlEntry struct {
	Token    string   `yaml:"token"`
	Cleanup  string   `yaml:"cleanup"`
	Packages []string `yaml:"packages"`
}
```
Field names, types, and declaration order are identical between `Entry` and `yamlEntry`; only
the yaml struct tags differ (irrelevant to Go's conversion rule, which ignores tags for
struct-to-struct convertibility since Go 1.8). `yamlEntry(e)` is therefore a legal, lossless
conversion — no field is dropped, silently zeroed, or reordered. Confirmed by direct read of
both struct definitions and a clean `go build`/`go test` (see below).
